# parlinfo brand assets

The ring is the brand: green = Ja, red = Nein, grey = Enthaltung. The parent mark has no letters; each parliament adds its code (ZH, CH, …).

| Colour | Hex |
| --- | --- |
| Background (petrol) | `#0B2E34` |
| Ja | `#2FE39B` |
| Nein | `#FF5C57` |
| Enthaltung | `#6E8A90` |
| Secondary text | `#A9C1C5` |

Typeface: Inter (800 for the wordmark, 500 for the country code). All SVG text is outlined, so no font is needed to render them.

## Files

- `svg/parlinfo-mark.svg`: parent mark (rounded square)
- `svg/parlinfo-zh-mark.svg`, `svg/parlinfo-ch-mark.svg`: chamber marks (rounded square)
- `svg/parlinfo-zh-avatar.svg`, `svg/parlinfo-ch-avatar.svg`: full-bleed squares for circular profile crops
- `svg/parlinfo-wordmark*.svg`: wordmark (white, for light backgrounds, with dark background built in)
- `parlinfo-readme-header.png`: README header (2560×640)
- `social/`: platform uploads: GitHub social preview, plus profile picture and X / Bluesky / Facebook banners for each of `parlinfo-zh-*` and `parlinfo-ch-*`
